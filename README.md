# ⌨️ SPEED TYPING TEST

### Python Programming Project – ECA1121

A simple and interactive **Speed Typing Test application** developed using Python to measure typing speed and accuracy. The application allows users to test their typing skills by typing a displayed sentence within a given time and provides performance results based on Words Per Minute (WPM) and typing accuracy.

---

## 📌 Project Overview

The Speed Typing Test is a beginner-friendly Python application designed to evaluate and improve users' typing skills.

The application displays a predefined sentence to the user and records the time taken to type it. After completing the test, it calculates the typing speed in Words Per Minute (WPM) and accuracy by comparing the entered text with the original sentence.

This project demonstrates Python programming concepts such as string manipulation, user input, time management, conditional statements, and basic logic implementation.

---

## 🎯 Objectives

- To measure users' typing speed in Words Per Minute (WPM).
- To calculate typing accuracy through character-by-character comparison.
- To provide an interactive typing practice environment.
- To improve typing speed and efficiency.
- To implement Python programming concepts in a real-world application.
